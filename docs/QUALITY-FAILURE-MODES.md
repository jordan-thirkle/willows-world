# Willow's World — Quality Failure Modes

Watch for these recurring traps:

- **demo substitution:** a pretty screen is treated as end-to-end product proof;
- **native substitution:** responsive web is treated as iOS/Android verification;
- **output drift:** landscape/vertical/app versions acquire separate episode truth;
- **AI truth drift:** generated transcript/art/story detail silently overrides real/parent-confirmed source;
- **approval drift:** an old approval continues after publication-relevant revisions change;
- **privacy drift:** convenient public URLs/client payloads expose private family state;
- **rights drift:** accessible/popular content is assumed publishable;
- **scope drift:** new destinations/features displace the founding loop;
- **process drift:** documentation/agent frameworks become the work instead of enabling it;
- **evidence drift:** old or unrun checks are reported as current passes.

Critics and tests should actively look for these, especially before merge/release.

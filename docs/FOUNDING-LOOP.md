# Willow's World — Founding Loop

## Record
Capture/import a real reading performance privately. Preserve the source and provenance before deriving anything.

## Transform
Create non-destructive audio/transcript/timing/scene/art derivatives. Parent reviews/corrects the interpretation and approves exact revisions.

## Watch / Play
Story Woods consumes the approved performance/scene plan. The real voice drives synchronized words/scenes; learning events update the world durably.

## Share
The same approved performance produces landscape/vertical/caption/thumbnail derivatives. Export/publication is parent-controlled and rights-aware; public projection contains only approved safe fields/assets.

Every P0 implementation task should improve at least one step or the durable handoff between steps.

# Project boundary

Use this document when a proposed feature could plausibly belong to another product.

## Willow's World owns

- real reading/performance capture
- AI-assisted audio/transcription/timing/scene production
- Story Woods and interactive read-alongs
- consistent Willow/world artwork and animation
- learned words and world changes arising from the experience
- one approved performance producing app, 16:9 and 9:16 outputs
- parent preview/approval/export controls
- the later Word Garden, Maker Meadow, Discovery Hill and game/creative extensions when they grow from this world

## Admission test

A feature can enter the implementation backlog when at least one is true:

1. it directly improves **Record → Transform → Watch / Play → Share**;
2. it is required to make an already-approved Willow's World experience work safely/reliably;
3. the product owner explicitly chooses to expand Willow's World and that decision is recorded in a repository issue/spec.

If none is true, keep it outside this repository.

## Context hygiene

Treat repository evidence as authoritative for product identity. Conversation history can supply detail, but it cannot silently redefine the repository. When similarly themed projects exist, retrieve/use only the context needed for the named project and validate it against the North Star before writing.

## Completion check for every meaningful PR

The PR description should be able to answer: **Which part of the Willow's World north star does this change improve?**

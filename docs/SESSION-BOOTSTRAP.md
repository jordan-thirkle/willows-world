# Willow's World — Session Bootstrap

Use this at the beginning of a fresh coding session:

1. fetch/pull latest repository state;
2. inspect branch/working tree/recent commits/open PRs/issues;
3. read `docs/README-START-HERE.md` and linked current-state/next/plan documents;
4. run the repository's existing baseline verification before changing code where practical;
5. inspect the exact current implementation files for the next slice rather than assuming target paths from plans;
6. create/use a focused branch/worktree;
7. execute the smallest current-gate vertical slice with tests and platform evidence;
8. run critics/review, fix valid findings, persist evidence and continue.

Plans may contain target paths that must be reconciled with the real repository before editing. Existing repository conventions win unless the approved design intentionally changes them.

# Willow's World — Autonomous Stop Condition

A coding session should normally stop only when one of these is true:

- the next required action needs a genuine unresolved owner/product decision;
- an irreversible/public/account action needs explicit confirmation;
- required credentials/private input are unavailable and no safe alternative exists;
- all safe unblocked work in the approved current slice/gate is exhausted;
- evidence invalidates the approved design enough that continuing would create waste/risk.

Tool friction, completion of one task, or the existence of additional later work are not by themselves stop conditions.

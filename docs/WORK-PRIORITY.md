# Willow's World — Work Priority

Score candidate work qualitatively in this order:

1. Does it unblock a required capability in the earliest incomplete gate?
2. Does it reduce a critical/high privacy, rights, data-loss or release risk?
3. Does it materially improve the defining parent/child experience?
4. Does it create reusable evidence/durable boundaries needed by multiple later surfaces?
5. Can it be delivered as a small independently testable vertical slice?

Work that only improves polish, architecture elegance or future optionality ranks below a missing gate capability unless the current product quality is itself the gate blocker.

When two tasks are similar priority, prefer the one that creates direct user-visible evidence sooner.

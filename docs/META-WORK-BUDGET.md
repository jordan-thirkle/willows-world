# Willow's World — Meta-work Budget

Process, documentation, skills and automation are useful only when they improve product execution, safety, verification or continuity.

After this operating-model foundation is merged, default effort returns to P0 implementation. Create additional process documentation only when a concrete recurring failure, ambiguity or release requirement justifies it.

A useful meta-work change should answer at least one question:

- What blocker does this prevent/remove?
- What verification does this make reproducible?
- What safety/rights failure does this enforce against?
- What handoff ambiguity does this eliminate?
- What repeated manual work does this reliably reduce?

If none apply, build the product instead.

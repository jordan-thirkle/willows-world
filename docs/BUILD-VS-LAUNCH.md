# Willow's World — Build vs Launch

## Built
A capability exists in code/assets/configuration.

## Implemented
The capability's focused tests/checks pass on the development branch.

## Verified
Platform-appropriate runtime evidence confirms the capability for the relevant candidate.

## Launch ready
All capabilities required by the applicable release gate are verified together, safety/rights/operations are satisfied and the exact candidate is ready for distribution.

This distinction prevents a long feature list from being mistaken for a shippable product.

# Willow's World — Durable Decisions

## 2026-08-17 — Four-gate launch model approved

Willow's World uses the following release progression:

`P0 product proof → P1 native/private beta → P2 public/store launch → P3 organic growth → post-launch expansion`

The founding loop remains **Record → Transform → Watch / Play → Share**.

## 2026-08-17 — Professional operating hierarchy approved

Priority order is:

1. child safety/privacy/rights/preservation;
2. product truth and source fidelity;
3. current-gate product quality;
4. reliability and verification;
5. distribution readiness;
6. discoverability/growth;
7. expansion.

Completion requires evidence, not an agent assertion.

## 2026-08-17 — Project boundary reaffirmed

The childhood archive project is separate. It can inform By JTT standards around provenance, preservation and professional operation, but Willow's World does not inherit its feature scope.

## 2026-08-17 — Platform direction reaffirmed

Expo/React Native is the primary iOS/Android family application foundation. Next.js owns public/discoverable web where SSR/metadata/routing add value. Remotion renders deterministic video outputs. Shared durable domain records sit below those delivery surfaces.

## 2026-08-17 — Rights and publication are separate gates

The ability to ingest, transform, play or render material does not establish the right to publish it. Internal development performances may prove the technical pipeline while public launch uses explicitly rights-safe material and approval records.

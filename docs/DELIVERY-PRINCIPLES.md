# Willow's World — Delivery Principles

- Ship vertical evidence, not horizontal scaffolding.
- Keep the current working experience visible while replacing mocks beneath it.
- Tests protect domain truth; browser/device/render inspection protects experience truth.
- One approved record should feed every output that represents the same performance.
- Expensive processing is resumable and versioned.
- Private/public boundaries are explicit state transitions, not UI conventions.
- Provider choices are replaceable implementation details.
- A blocker should produce investigation and an alternative path, not indefinite inactivity.
- Release quality is the weakest applicable gate, not the strongest demo.

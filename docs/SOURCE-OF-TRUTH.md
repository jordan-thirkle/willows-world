# Willow's World — Source of Truth

For each performance:

- immutable source recording identity/hash is source evidence;
- parent-approved transcript/timing corrections are canonical interpretation;
- approved scene-plan/asset revision is canonical presentation intent;
- learning events are canonical progression history;
- publication approvals are canonical sharing authority;
- rendered videos/images/captions are derived outputs.

Do not make a rendered MP4, generated image, AI transcript response or React component the only place canonical information exists.

# Willow's World — Public SEO Guardrails

Organic search should make genuinely useful public Willow's World material easier to discover.

## Do
- create clear product, safety/privacy/support and rights-safe editorial/episode pages;
- use accurate descriptive titles/copy matching visible content;
- provide canonical URLs, sitemap/robots and valid share/structured metadata;
- make public pages fast, accessible and useful without JavaScript-only hidden meaning;
- measure relevant search discovery and conversion.

## Do not
- create thin keyword permutations at scale;
- expose private family/child details for long-tail traffic;
- duplicate third-party story text to capture search demand without rights;
- stuff keywords into child-facing Story Woods UI;
- treat AI-generated volume as an organic strategy.

By JTT authority should come from useful original product/build/learning content and a genuinely good product, not SEO theatre.

# Willow's World — Product Metrics

Metrics exist to tell us whether the product and production system work, not to maximize a child's screen time.

## P0 quality
- recording/import success rate;
- transcript/timing review completion;
- playback sync drift/failures;
- render success/failure/retry rate;
- parent approval/rejection reasons;
- successful completion of Record → Transform → Watch / Play → Share.

## P1 reliability
- native crash/error rate;
- media permission/import failure rate;
- restart/recovery success;
- persistence/auth failures;
- export/delete success.

## P2 launch health
- release/deployment failures;
- publication projection failures/leakage alerts;
- support issues by category;
- store/web conversion from qualified parent intent.

## P3 discovery
- qualified organic landing visits;
- search impressions/clicks for genuinely relevant queries;
- public episode/editorial discovery where rights permit;
- store/download intent;
- parent activation into the production loop.

## Explicit non-goals
Do not optimize child session length, compulsive streaks, notification pressure or behavioural-ad engagement.

# Willow's World — Release Blocker Classes

## P0 blocker
Prevents the founding loop from working or being verified: ingest/review/play/progression/render/approval/persistence within the P0 scope.

## P1 blocker
Prevents trustworthy private iOS/Android use: native runtime, durable private data, authorization, export/delete, recovery or reproducible builds.

## P2 blocker
Prevents responsible public/store distribution: rights, public/private boundary, privacy/support, accurate store declarations, release candidate, monitoring/rollback.

## P3 blocker
Prevents intended organic discovery after product launch: production crawlability/metadata/search tooling or approved distribution workflow.

A later-gate blocker does not automatically block earlier private engineering. Record it and continue the earliest gate unless the issue creates immediate safety/data-loss risk.

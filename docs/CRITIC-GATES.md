# Willow's World — Critic Gates

Critics exist to falsify weak completion claims and improve the product, not to generate ceremony.

## Product critic

Pass when the tested slice materially improves the current release gate and a real parent/child workflow. Fail when work is architecture theatre, generic feature accumulation or detached from Record → Transform → Watch / Play → Share.

## Privacy/child-safety critic

Pass when private source media is protected, collection is minimal, publishing is parent-controlled and no public route can infer/access private family state. Fail on implicit publishing, guessable private media, child social graph/DMs, behavioural-ad targeting or unnecessary sensitive telemetry.

## Rights/provenance critic

Pass when every publishable source has explicit rights/provenance state and outputs remain traceable to approved source/revision. Fail when technical capability is treated as permission to publish.

## Experience/design critic

Pass when Willow's World feels like an authored children's universe, mobile-first and accessible, with clear child/parent modes and no generic AI-dashboard aesthetic. Verify visually; code structure alone cannot pass this gate.

## Engineering critic

Pass when domain truth is not trapped in UI/provider state, expensive pipeline steps are resumable/versioned, tests cover material behavior, and changes are understandable/reversible. Fail on duplicated canonical episode state, destructive processing or unnecessary platform coupling.

## Reliability critic

Pass when restart, interruption, stale revisions, failed renders/uploads and retry behavior preserve canonical data and produce understandable recovery. Fail when a failed derived step requires repeating or risking source ingest.

## Native critic

Pass only with actual iOS/Android build/runtime evidence appropriate to the release gate. A responsive browser screenshot is not native-app evidence.

## Web/SEO critic

Pass when public pages render meaningful crawlable content and intentional metadata/canonicals/sitemap/robots/schema where valid. Fail on keyword stuffing, thin programmatic pages or contaminating private/child UI for SEO.

## Release critic

Pass only when a clean release candidate can be reproduced, verified, monitored and rolled back, and store/public declarations match actual data behavior.

## Growth critic

Pass when distribution attracts qualified parents/families/readers through useful public content and approved media. Fail when success depends on spam, manipulative child engagement or vanity traffic disconnected from product value.

# Willow's World — Project Manager Loop

At each checkpoint:

1. What is the earliest incomplete gate?
2. What verified evidence is missing for that gate?
3. Which missing item is highest risk/value and currently unblocked?
4. What is the smallest vertical slice that creates direct evidence for it?
5. Which critics/platform checks must review that slice?
6. After merge, did gate status actually change?
7. What is now the next highest-value slice?

Do not use feature count, code volume or agent activity as substitutes for these questions.

# Willow's World — P2 Acceptance Contract

P2 proves Willow's World can be responsibly distributed outside the private development/family environment.

## Scenario

Given a verified native/web release candidate and publication-rights-safe content,
when a parent explicitly approves a publishable revision,
then only its sanitized public projection can reach public web/media destinations,
while private source recordings, learning history and internal review data remain private,
and public/store support/privacy/data declarations match actual product behavior.

## Required evidence

- public/private leakage and stale-approval tests;
- rights eligibility recorded for launch content;
- production web/support/privacy/delete-account routes verified;
- iOS/Android release candidates verified;
- current platform declarations reviewed against actual data behavior;
- release assets/metadata reflect the current product;
- monitoring and rollback/recovery path verified;
- final launch evidence references exact commit/build/version.

P2 is not passed by merely having a Vercel URL or compiling an app binary.

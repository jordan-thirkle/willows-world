# Willow's World — Professional Operating Model

## Strategy
One differentiated family product, one defining loop, four evidence gates.

## Product management
Earliest incomplete gate controls priority. Depth before breadth. User/safety evidence can change the roadmap.

## Engineering
Vertical slices, durable domain truth, replaceable providers, test-first where behavior warrants it, PR/review, fresh verification.

## Design
Authored storybook world, mobile-first, accessible, coherent character/world continuity, no generic AI-product aesthetic.

## Production
One approved performance feeds app/video/short outputs with provenance and revision traceability.

## Safety/rights
Private by default. Minimum data. Explicit publication approval. Rights eligibility separate from technical capability.

## Release
Web/iOS/Android claims require matching platform evidence. Store/public release requires exact-candidate evidence, monitoring and rollback.

## Growth
SEO/media/X amplify verified public-safe product value; they never justify exposing private child data or optimizing compulsive child engagement.

## Operations
GitHub is durable memory. Blockers are investigated and routed around where feasible. Handoffs record verified state and exact next action.

# Willow's World — Documentation Policy

Keep one primary owner for each kind of truth:

- product promise/P0: `PRODUCT.md`
- project separation: `PROJECT-BOUNDARY.md`
- architecture: `PLATFORM-ARCHITECTURE.md`
- operating hierarchy: `OPERATING-MODEL.md`
- release progression: `ROADMAP.md`
- actual handoff: `CURRENT-STATE.md`
- immediate action: `NEXT.md`
- evidence requirements: `VERIFICATION-MATRIX.md`
- active blockers: `BLOCKER-LOG.md`

Supporting documents may elaborate but should not contradict these owners. When a durable decision changes, update the owner first and then dependent summaries.

Avoid creating new documentation when an existing owner can be updated clearly. This policy applies after the current operating-model foundation is merged.

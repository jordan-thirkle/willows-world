# Willow's World — Quality Optimization Order

When improving a slice, optimize in this order:

1. correctness/safety of canonical data and permissions;
2. whether the real user flow works end-to-end;
3. recovery/reliability under failure;
4. accessibility/native usability;
5. visual/audio craft and emotional quality;
6. performance/efficiency where measured;
7. discoverability/growth for public surfaces.

This does not make visual craft unimportant; it prevents beautiful output from hiding broken truth/safety foundations.

# Willow's World — Product Boundary Test

Before accepting a feature, ask:

1. Does it strengthen real reading/learning/creative family moments or the world that grows from them?
2. Does it depend on or improve the founding production loop?
3. Is it specific enough to Willow's World that it would not fit unchanged into any generic children's app?
4. Is its release-gate priority higher than unresolved core work?
5. Does it preserve parent control, privacy and source truth?

If the feature mainly belongs to the separate childhood archive product, a generic social app, a generic activity bundle or an SEO content machine, it should not enter Willow's World by default.

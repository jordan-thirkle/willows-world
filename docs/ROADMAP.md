# Willow's World Roadmap

## Current critical path

**P0 Product-complete alpha** is the active gate.

North star: **Record → Transform → Watch / Play → Share**.

### P0 — Product-complete alpha

- [ ] Canonical versioned StoryPerformance/ScenePlan/LearningEvent/PublicationApproval contracts
- [ ] Safe Episode 001 fixture and private real-media path
- [ ] Deterministic synchronized Story Woods playback
- [ ] Parent transcript/timing/scene review and approval
- [ ] Persistent learning/world progression
- [ ] Landscape + vertical Remotion outputs from the same approved performance
- [ ] Parent-gated export/publication
- [ ] Web/mobile/accessibility/restart verification evidence

### P1 — Distribution-complete beta

- [ ] Expo iOS family client completes P0 loop
- [ ] Expo Android family client completes P0 loop
- [ ] Durable relational/object persistence
- [ ] Minimum parent identity/private-data authorization boundary
- [ ] Export and deletion pathways
- [ ] Privacy-safe crash/error observability
- [ ] Offline/interruption/recovery/device QA
- [ ] Reproducible release/build verification

### P2 — Public-launch complete

- [ ] Public/private publication projection boundary
- [ ] Publication-rights-safe launch content
- [ ] Privacy/support/terms/delete-account surfaces
- [ ] App Store release candidate + metadata/assets/declarations
- [ ] Play Store release candidate + metadata/assets/declarations
- [ ] Production By JTT web domain/subdomain
- [ ] Monitoring/rollback/release evidence
- [ ] Store/public launch gate passes

### P3 — Organic-growth launch

- [ ] High-quality public Willow's World landing surface
- [ ] Crawlable public content architecture
- [ ] Metadata/canonicals/Open Graph/sitemap/robots/valid structured data
- [ ] Search Console + privacy-safe analytics
- [ ] Approved YouTube landscape distribution workflow
- [ ] Approved vertical/short-form distribution workflow
- [ ] Authored X.com launch/progress system
- [ ] Qualified discovery/conversion metrics

## After launch

Only after the preceding gates are healthy should roadmap priority expand materially into Maker Meadow, Discovery Hill, broader games, social systems or monetization. New destinations must strengthen the distinctive Willow's World proposition rather than turn the product into a generic children's activity bundle.

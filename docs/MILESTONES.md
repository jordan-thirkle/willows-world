# Willow's World — Milestones

## M1 — Episode contract
One versioned safe performance record drives the existing Story Woods slice and rejects stale/missing publication approval.

## M2 — Story Woods truth
Playback/word/scene state is deterministic and progression reconstructs from explicit events.

## M3 — Parent production loop
Transcript/timing/scene review and approval are real, revisioned product behavior.

## M4 — One performance, many outputs
Interactive player plus landscape/vertical/captions consume the same approved performance.

## M5 — Durable private product
Canonical records/media persist safely and survive restart/provider/UI changes.

## M6 — Native family beta
Verified iOS/Android clients complete the founding loop with family-data controls.

## M7 — Public-safe launch system
Explicit publication projection, rights-safe content and support/privacy surfaces exist.

## M8 — Store/web release
Verified production web and native release candidates satisfy launch evidence gates.

## M9 — Organic discovery
Public web, search, approved media and By JTT distribution form a measured acquisition system.

Milestones describe outcomes. Implementation details may change without changing the milestone if evidence shows a better route.

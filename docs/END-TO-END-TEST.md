# Willow's World — End-to-End Test Story

The long-term release test is one coherent story:

A parent signs into the family product, privately imports a real reading, the source is preserved, AI-assisted production proposes a timed interpretation, the parent corrects/approves it, Story Woods plays the real voice with synchronized scenes/words, completion changes persistent world state, the parent previews landscape/vertical outputs, and only an explicitly approved rights-eligible revision can become public.

The same family can later return on supported devices and recover the experience. Public visitors see only sanitized approved material through a professional discoverable web presence. Release/support/privacy behavior matches the actual iOS/Android/web product.

Every release gate is a progressively stronger proof of this story.

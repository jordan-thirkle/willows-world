# Willow's World — Product Truth Test

At any point, ask:

> Can a normal real reading moment become a polished Willow's World experience without fabricating the child's performance, losing the source, duplicating episode truth across outputs, or publishing anything the parent did not deliberately approve?

If the answer is no, the earliest reason why is probably higher priority than adding another feature.

For public launch add:

> Can that experience run as a trustworthy iOS/Android product and professional public web presence using rights-safe content, with evidence that privacy, recovery and distribution work?

These questions are deliberately harder to game than feature counts.

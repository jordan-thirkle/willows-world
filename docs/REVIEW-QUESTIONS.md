# Willow's World — Final Review Questions

Before approving a material slice/release candidate:

- What user outcome became possible/better?
- What exact evidence proves it?
- What could still make this claim false?
- Did any canonical/private data move into a less safe boundary?
- Did rights/publication state become ambiguous?
- Did we duplicate episode truth across app/video/web?
- Did we verify on the platform we are claiming?
- Did this introduce scope not required by the current gate?
- Can another agent/contributor reproduce and continue this work from GitHub alone?

If the answers are weak, the work needs another iteration rather than stronger wording.

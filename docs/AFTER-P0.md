# Willow's World — After P0

When P0 genuinely passes, do not immediately explode scope.

1. Freeze a verified P0 candidate and evidence record.
2. Identify which web/prototype logic becomes shared packages versus native-specific UI.
3. Build/verify Expo iOS/Android vertical parity around the proven loop.
4. Introduce production-suitable private persistence/identity/export/delete as required for private beta.
5. Run P1 device/reliability/accessibility/security critics.
6. Only then promote public/store work to the active completion gate.

World expansion can begin in bounded parallel discovery only when it does not destabilize native/private launch work.

# Willow's World — Public Launch Checklist

This checklist is intentionally short; detailed evidence lives in the acceptance/verification documents.

## Product
- [ ] P0 verified
- [ ] P1 verified

## Safety and rights
- [ ] private/public projection verified
- [ ] launch content publication eligibility recorded
- [ ] parent approval semantics verified
- [ ] export/deletion/support/privacy paths verified

## Distribution
- [ ] production public web verified
- [ ] iOS release candidate verified
- [ ] Android release candidate verified
- [ ] store metadata/assets/declarations checked against current product/platform requirements

## Operations
- [ ] monitoring/health checks active
- [ ] rollback/recovery verified
- [ ] release evidence tied to exact candidate

## Discovery
- [ ] public metadata/canonical/sitemap/robots verified
- [ ] analytics/Search Console configured
- [ ] approved launch media/social material prepared

Do not check an item based on intention or documentation alone.

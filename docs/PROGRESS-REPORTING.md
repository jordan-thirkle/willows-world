# Willow's World — Progress Reporting

When reporting progress, separate:

## Changed
Concrete files/code/config/assets/PRs created or modified.

## Verified
Exact checks/runtime evidence that passed and the commit/build they apply to.

## Not yet verified
Implemented/proposed behavior that still lacks required evidence.

## Blocked
Named external/technical dependency, root cause if known, alternatives tried and next action.

## Next
Highest-value unresolved action in the earliest incomplete gate.

Avoid percentage-complete estimates unless backed by a clearly defined finite checklist; prefer milestone/gate status and evidence.

# Willow's World — Artifact Provenance

Every meaningful episode artifact should be traceable to the source/revision that produced it.

## Canonical
- source recording identity + content hash/private storage reference;
- source/story identity and rights state;
- parent-approved transcript/timing revision;
- parent-approved corrections;
- learning events;
- publication approvals.

## Derived
- cleaned audio;
- alignment suggestions;
- scene plans until approved as a referenced revision;
- generated/edited artwork;
- animations;
- captions;
- thumbnails;
- landscape/vertical renders.

Derived manifests should record relevant performance/scene/asset revision IDs and provider/tool version metadata needed for reproducibility.

Never overwrite canonical source evidence in place to make a derivative look cleaner. New processing produces a new derivative/revision.

# Willow's World — One Performance, Many Outputs

A single approved `StoryPerformance` revision plus its approved `ScenePlan`/asset revisions is the canonical input for:

- Story Woods interactive playback;
- learning/progression events;
- landscape video;
- vertical video;
- captions/subtitles;
- poster/thumbnail derivatives;
- approved public episode metadata.

Platform-specific layouts/editing may adapt presentation, but must not silently fork transcript timing, scene identity or episode facts into independent canonical copies.

If a platform requires a content change that changes the performance itself, create/review a new revision rather than patching one output privately.

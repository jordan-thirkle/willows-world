# Willow's World — Engineering North Star

For any real reading performance, Willow's World should be able to reconstruct exactly:

- which immutable source recording was used;
- what transcript/timing the parent approved;
- which scene/art revisions were shown;
- what learning events occurred;
- what outputs were rendered;
- what the parent approved for which destination;
- what was publicly projected;

And it should be able to do so even after replacing today's UI, renderer, AI provider or storage implementation.

That is the durability test behind the architecture.

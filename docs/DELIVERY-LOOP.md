# Willow's World — Sustained Delivery Loop

`select current-gate slice → define acceptance/failures → implement → verify → critic review → fix → PR/merge → update evidence/state → select next slice`

Repeat while safe unblocked work exists.

Do not insert a planning reset between every slice. Re-plan only when evidence changes architecture/product assumptions or the next slice is genuinely ambiguous.

This is how "keep going" becomes a durable engineering behavior rather than a chat instruction.
